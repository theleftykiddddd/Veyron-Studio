# VEYRON STUDIO

**Veyron Studio** is an advanced Geometry Dash development, analysis, performance profiling, and version control suite built as a native Geode mod for GD 2.2091 (Windows 64-bit). Designed for creators, decorators, verifiers, and level developers who demand professional IDE-grade tooling.

## Core Systems
1. **Studio Dashboard**: Real-time project telemetry, object counts, warning/error counters, and session overview.
2. **Advanced Level Analyzer**: Structural inspection for triggers, duplicate objects, out-of-bounds items, and heuristic diagnostics.
3. **Performance Profiler**: Real-time FPS monitoring, frame-time spikes tracking, and heatmapping.
4. **Frame Analysis System**: Input timing recording, frame-window statistics, and macro format adapters.
5. **Color & Group Manager**: ID dependency graphs, unused ID identification, and object filtering.
6. **Version Control**: Snapshot serialization, diff comparison (added/removed/modified), and rollback backups.
7. **Level Structure Visualizer**: Multi-mode visual mapping of level architecture.
8. **Project Manager**: Project profiles, notes, and local storage management.
9. **Settings & Customization**: Monochromatic IDE theme, diagnostic sensitivity, and telemetry controls.

## Build Instructions
1. Ensure you have the Geode CLI installed.
2. Clone this repository into your Geode mods directory or build via CMake.
3. Run `geode build` in the project root.
